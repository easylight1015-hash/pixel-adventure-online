# 像素冒險 Online（MVP 0.1）

一個以 **Node.js + 原生 Canvas + WebSocket** 製作的 2D 俯視角多人線上 RPG 原型，目標是先用零預算在本機測試 2～10 位玩家。

## 目前已實作

- 俯視角像素風地圖、村莊房屋、道路與森林裝飾
- WASD／方向鍵移動，伺服器端計算角色位置
- WebSocket 多人房間：同一個伺服器上的玩家可互相看見
- 測試房間最多 10 人
- 即時攻擊：空白鍵或按「攻擊」，伺服器檢查距離與攻擊冷卻
- 史萊姆 HP、擊敗後獲得經驗值、升級、怪物 8 秒後重生
- 玩家清單、HP／EXP UI、簡易冒險紀錄
- 不需要付費遊戲引擎；前端不需編譯

## 尚未實作／尚未驗證

- **尚未部署到公開網路**：目前設計為本機啟動與同一區域網路測試
- 尚未做正式壓力測試，10 人是房間程式上限，不代表已驗證可穩定承載 10 人
- 尚未加入帳號、密碼、資料庫、角色存檔、交易、背包、裝備、任務、聊天頻道
- 尚未做防外掛、加密登入、管理員工具、封鎖與舉報
- 目前怪物為固定位置的共享目標，沒有 AI 尋路或怪物反擊
- 尚未做手機觸控搖桿、音效、正式美術素材、地圖切換與副本
- 尚未針對瀏覽器相容性、斷線恢復或大量訊息做完整測試

## 需求

- Node.js 18 或更新版本（建議使用目前仍受支援的 LTS 版本）
- 可使用現代瀏覽器（Chrome、Edge、Firefox）

## 啟動方式

1. 安裝 Node.js：<https://nodejs.org/>
2. 解壓縮專案 ZIP，進入 `pixel_adventure_online` 資料夾。
3. 在該資料夾開啟終端機／命令提示字元。
4. 執行：

   ```bash
   npm install
   npm start
   ```

5. 瀏覽器開啟 <http://localhost:3000>。
6. 輸入角色名稱，按「進入世界」。

## 如何測試多人

- 同一台電腦：開兩個不同瀏覽器，或使用一般視窗與無痕視窗，各自開啟 `http://localhost:3000`。
- 同一個 Wi-Fi／區域網路：其他裝置在瀏覽器輸入主機電腦的區域網路 IP，例如 `http://192.168.1.20:3000`。請將範例 IP 換成實際 IP，並允許防火牆通過 3000 埠。
- **不要把這個原型直接當正式線上遊戲公開營運**。正式公開前需補上安全性、持久化資料、濫用防護與壓力測試。

## 常見問題

- `npm` 不是內部或外部命令：Node.js 尚未安裝，或安裝後未重新開啟終端機。
- `EADDRINUSE`：3000 埠已被使用；可在 Windows PowerShell 設定 `$env:PORT=3001`，macOS/Linux 可執行 `PORT=3001 npm start`。
- 其他裝置無法連線：確認裝置在同一個網路、主機 IP 正確、作業系統防火牆允許連入 TCP 3000。
- 連線錯誤：先確認終端機仍在執行 `npm start`，再重新整理網頁。

## 架構簡述

- `public/game.js`：Canvas 繪圖、鍵盤輸入、UI、向伺服器送出輸入與攻擊指令。
- `server.js`：HTTP 靜態檔案服務、WebSocket 連線、角色移動、攻擊距離／冷卻、怪物 HP 與經驗值。
- 伺服器每 50ms 廣播一次世界狀態（約 20 次／秒）。角色位置與傷害由伺服器處理，避免單純相信客戶端傳來的座標或傷害值。

## 零預算路線

本機開發與測試可免費進行。若要讓不同地點的朋友透過網際網路連入，需要部署伺服器或使用可用的免費額度；免費方案可能有睡眠、流量或連線限制，請先確認服務商最新條款。正式營運通常需要持續維護與伺服器成本。


## 免費公開部署（Render + GitHub）

這是免費優先的試玩方式，適合早期測試，不是 24 小時營運保證。

1. 建立 GitHub 帳號：<https://github.com/>。
2. 在 GitHub 建立一個新的 repository，例如 `pixel-adventure-online`。
3. 把本專案資料夾內的所有檔案上傳到 repository 根目錄（包含 `package.json`、`server.js`、`render.yaml` 與 `public/`）。
4. 建立 Render 帳號：<https://render.com/>，選擇 **New → Blueprint**，連結 GitHub 並選取該 repository。
5. Render 會讀取 `render.yaml`。確認服務方案為 Free，然後建立並等待部署完成。
6. 部署成功後，Render 會提供一個 `https://....onrender.com` 網址。用該網址開啟遊戲；前端會自動使用 `wss://` 連接 WebSocket。
7. 請用不同網路（例如手機行動網路與家用 Wi-Fi）開啟同一網址測試多人連線。

### 免費方案注意事項

- Render 免費 Web Service 閒置 15 分鐘後可能休眠；再次訪問時可能要等待約一分鐘喚醒。
- 本專案會每 30 秒由瀏覽器送出輕量 heartbeat，讓活躍連線的閒置遊戲也有入站 WebSocket 訊息；若沒有玩家連線，服務仍可能休眠。
- 免費服務可能因平台維護、重啟或網路問題中斷；玩家連線與遊戲即時狀態可能丟失。
- 目前角色資料只存在記憶體，伺服器重啟後玩家、怪物狀態會重置；尚無帳號與持久化存檔。
- 請檢查 Render 當期的免費額度、流量與方案條款。不要在未確認支出上限前新增付費服務。
